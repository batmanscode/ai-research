The correction

`VVVVVVV` was not the wild type.

The first analysis counted non-valine residues. Canonical mapping showed that the all-valine sequence is an engineered anchor. The analysis was retracted and rebuilt with the native cores.

The useful inductive bias

Aggregate first. Transfer second.

The seven randomized sites are buried, but their ordinal positions are not homologous across these unrelated folds. The model therefore summarizes property changes without assigning a common “site 1” or “site 7.”

7 core residues→signed + absolute property changes→11–16 invariant features→ridge ranking
Useful failure: adding naive position-specific 3D features reduced held-backbone performance in all three folds.

The evidence boundary

A fourth backbone is the decisive experiment.

  1. 01Freeze the current features, penalty grid, and metrics before labels.
  2. 02Assay 1,000–2,000 QC-passing variants across mutation-count strata.
  3. 03Use at least three independently prepared biological replicate libraries.
  4. 04Report the result whether it confirms or falsifies transfer.
