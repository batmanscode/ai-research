Solved theorem · connected induced-P₅-free graphs · α ≥ 3

The answer is
exactly 4/3.

How many guards does a network need if every guard must be able to answer an attack without leaving the rest exposed? A published upper bound was 3/2 times a natural graph parameter. The sharp multiplier is smaller: 4/3.

γs(G)≤ α(G) + 1≤4α(G) / 3

γs is the fewest secure guards. α is the largest group of mutually nonadjacent vertices. The statement assumes α ≥ 3.

First, the game

A secure guard has to move—and leave no hole behind.

1

Cover

Every unguarded vertex touches a guard. This is ordinary domination.

2

Answer

When an unguarded vertex is attacked, one adjacent guard swaps into it.

3

Stay safe

After that swap, every vertex must still be covered. The smallest team that always can do this is γs.

What does P₅-free mean? The network contains no five-vertex route whose only links are the four consecutive ones. That missing pattern forces surprisingly strong global structure.

How the proof was found

The wrong turns left useful landmarks.

  1. 01

    The stronger guess failed

    The 12-vertex witness disproved γs ≤ α, but exposed the sharp lower ratio 4/3.

  2. 02

    Easy graph structures fell away

    Cut vertices, dominating pairs, and dominating three-vertex paths were proved to satisfy γs ≤ α + 1.

  3. 03

    Cliques became the whole battlefield

    Triangles were closed first. Larger minimal dominating cliques split into private regions and multi-hub neighbours.

  4. 04

    A tempting edge lemma broke

    A 12-vertex SAT witness killed the claim that every dominating edge extends directly to a secure triple. The proof target was changed instead of forced.

  5. 05

    The last cross edge became a path

    A private-region edge forces one hub plus its two endpoints to dominate the graph. That drops the final case back into the solved path branch.

Solved—and not claimed beyond scope

The coefficient question is closed for the published connected α ≥ 3 class.

  • Solved: the best universal coefficient is 4/3.
  • Still open here: a clean classification of every equality graph.
  • Finite evidence only: whether the 12-vertex witness is minimum order.
  • Outside the theorem: α = 2, disconnected graphs, or graphs containing an induced P₅.
